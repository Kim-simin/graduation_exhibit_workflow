# 학생 게시물 제거 및 전시 홈페이지 연결 전환

## 적용 범위
- 기존 학생 프로필, 학생 프로젝트 JSON, 전시의 artworks/works 배열 제거.
- 연결된 학생 미디어를 public 폴더 밖 `.private-removal-backups/`로 이동. Git 제외.
- 웹 포스터는 targetUrl의 HTTP(S) 주소로 연결. 누락된 주소를 임의로 만들지 않음.
- 기존 전시 상세 URL도 외부 전시 홈페이지로 리다이렉트.
- 학생 조회·신규 등록 화면 중단. 공식 전시 및 기업 데이터 유지.
- Publish 파이프라인에서 학생 및 출품작 재공개 차단.

## 남은 운영 작업
- 변경은 로컬 작업본 기준이며 Vercel 재배포가 필요하다.
- Supabase 서비스 권한이 없어 원격 학생 게시물의 실제 삭제는 미확인이다. 클라이언트 조회 차단은 DB 삭제나 RLS 차단을 대신하지 않는다.
- 이전 배포 URL, CDN, 공개 Git 과거 커밋, 외부 저장소, 기존 SNS 게시물은 별도 삭제가 필요하다.
- 복구용 로컬 백업은 영구 파기가 아니다. 확인 후 보존 근거와 기간을 정하고 파기해야 한다.
- 로컬 자동 수집기를 재실행하면 원천 데이터가 다시 수집될 수 있으므로 학생 작품 수집 작업은 재개하지 않는다.

## 법적 잔여 쟁점
1. 포스터도 저작물일 수 있다. 외부 홈페이지 링크를 붙여도 플랫폼에 저장·표시한 포스터의 복제·공중송신 문제는 별개다. 허락·라이선스를 확인하고 불명확하면 텍스트 링크로 대체한다.
2. 공개된 이름·학과·연락처라고 해서 재수집·재게시가 자동으로 허용되는 것은 아니다. 처리 근거·목적·보유 기간을 확인한다.
3. 현재 삭제가 과거 게시에 대한 책임을 자동 소멸시키지는 않는다. 삭제 요청·권리 주장에는 이력을 보존하며 대응한다.
4. 공식 제휴나 대학의 승인을 받은 서비스로 오인시키는 표현은 사용하지 않는다. 링크 목적지의 권한과 진위도 확인한다.
